# Ansari Habibullah Atik | Frontend Developer Portfolio

A responsive portfolio website with four frontend demo projects, built with **HTML5, CSS3 and JavaScript** (no frameworks, no build step).

**Live site:** https://habibullah-ansari.github.io/

## Projects

| Project | What it shows | File |
|---|---|---|
| ShopSphere (E-commerce website) | Product search, categories, wishlist, product details, coupon code, cart and checkout form | `projects/ecommerce-website.html` |
| Spice Route Kitchen (Restaurant website) | Responsive landing page with tabbed menu, opening hours, reviews, booking form, local SEO data | `projects/restaurant-website.html` |
| TableTap (Restaurant management) | Table status, order taking, GST bill and daily sales (frontend demo) | `projects/restaurant-management.html` |
| IronFit (Gym management) | Members, plans, expiry tracking, check-ins and revenue summary (frontend demo) | `projects/gym-management.html` |

## Portfolio features
- Responsive layout with mobile menu, dark and light mode
- Resume viewer with PDF download, certificate viewer
- Contact form that opens email or WhatsApp with all project details
- SEO: meta tags, Open Graph, structured data (Person, FAQ)

## Run it locally
No installation needed. Download the folder and open `index.html` in a browser.

## Folder structure
```
index.html                  main portfolio page
projects/                   the four demo projects
Habibullah_Ansari_Resume.pdf
robots.txt, sitemap.xml     SEO files (update the URLs)
```

## Notes
- The projects are frontend demos. Data (cart, members, orders) is saved in the browser only. There is no server or real payment.
- Products, reviews, prices and orders in the demos are sample data.
- Built with the help of AI tools (Claude by Anthropic) and customised by me.
