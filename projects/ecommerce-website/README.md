# ShopSphere: E-commerce website demo

Product search, categories, wishlist, product details window, coupon code (WELCOME10), cart with quantity buttons, delivery charge rule, and a checkout form with address and payment method.

## Technologies
HTML5, CSS3 (Flexbox and Grid, responsive layout), JavaScript (no libraries, no build step).

## Files
```
index.html
css/style.css
js/script.js
images/products/ (8 product photos)
```

## Run it
Download this folder and open `index.html` in a browser. No installation needed.

## Notes
- This is a frontend demo. Data is saved in your browser only (localStorage). There is no server and no real payment.
- Products, prices, names and reviews are sample data.
